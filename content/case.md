# Кейс: реестр решений комитетов

Пилотный Cowork-кейс: папка протоколов + регламент + скан; 10 независимых L1 и 4 L2.

## Ловушки презентации

| Ловушка | В пилоте |
|---------|----------|
| Версии / изменения по ID | Да (в т.ч. Р-017 с двумя переносами) |
| Дистрактор-двойник | Нет |
| Правило в тексте | Да — `регламент.md` |
| Скан как единственный источник | Да — дата и номер протокола 05 |
| Неотвечаемые | L1-09, L1-10 |
| Минимальные пары | Нет (`stability` = not_measured_v0) |

## Отклонения от презентации

- 14 заданий вместо 8–12 / 10 на обкатку — чтобы развести 4 L2-способности.
- Отказы: 2/10 L1 (20%), 2/14 по кейсу ≈ 14.3%.
