## Текущее задание

Какая максимальная температура была зафиксирована при транспортировке образца S-015 проекта МТБ-26?

## Формат результата

Создайте файл `output/answer.json` со структурой ниже.
Пример показывает **только форму** полей — не подставляйте его как готовый ответ.
Если данных недостаточно — отказ: `answer` = null и `refused` = true.
В `sources` указывайте пути **относительно корня рабочей папки** (например `проекты/МТБ-26/...`), не только имя файла.

```json
{
  "answer": "<значение или null>",
  "sources": [
    "..."
  ],
  "refused": false
}
```

Затем завершите задачу (`claim_done`).
