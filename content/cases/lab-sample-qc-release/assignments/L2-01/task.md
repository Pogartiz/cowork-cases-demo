## Текущее задание

Подготовь XLSX-файл допуска образцов проекта МТБ-26 к секвенированию по действующему СОП на 30.09.2026. На листе «Допуск» для каждого из 6 образцов укажи концентрацию (Qubit), A260/280, объём, массу ДНК, результат по каждому из трёх критериев и общий вердикт. Масса, результаты по критериям и вердикт должны вычисляться формулами; если по образцу данных недостаточно, вердикт должен быть «Нет данных». На листе «Исключения» перечисли образцы, которые не допущены или не могут быть оценены, с причиной и ссылкой на пункт СОП. Сохрани в `output/допуск_образцов_МТБ-26.xlsx`.

Затем завершите задачу (`claim_done`).
