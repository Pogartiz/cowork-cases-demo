## Текущее задание

С какой карты проводилась оплата такси из аэропорта по командировке Колесова Д.Э. (последние 4 цифры)?

## Формат результата

Создайте файл `output/answer.json` со структурой ниже.
Пример показывает **только форму** полей — не подставляйте его как готовый ответ.
Если данных недостаточно — отказ: `answer` = null и `refused` = true.
В `sources` указывайте пути **относительно корня рабочей папки** (например `orders/Решение_о_командировании_Колесов.xlsx`), не только имя файла.

```json
{
  "answer": {
    "last4": "0000"
  },
  "sources": [
    "..."
  ],
  "refused": false
}
```

Затем завершите задачу (`claim_done`).
