## Текущее задание

Найти и выписать названия всех клеточных линий в файле KD-cells.docx, для которых трансфекция признана неудачной

## Формат результата

Создайте файл `output/answer.json` со структурой ниже.
Пример показывает **только форму** полей — не подставляйте его как готовый ответ.
Если данных недостаточно — отказ: `answer` = null и `refused` = true.
В `sources` указывайте пути **относительно корня рабочей папки** (например `Эксперименты/Трансфекции.xlsx`), не только имя файла.

```json
{
  "answer": {
    "lines": [
      "..."
    ]
  },
  "sources": [
    "..."
  ],
  "refused": false
}
```

Затем завершите задачу (`claim_done`).
