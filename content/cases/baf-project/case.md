## PNG L2 (схема A)

L2-01 / L2-02: агент сдаёт PNG по ТЗ + JSON sidecar для автопроверки чисел/подписи.  
Скоры: `png_present` ∧ `data_pass` = `task_pass`. Визуал графика (оси/пиксели) **не** автооценён — честно в отчётах.

L2-01: удельная продуктивность = титр (мг/л) / клетки (10⁶/мл) → эталонные числа в **мкг/(10⁶ клеток)**.  
L2-02 caption: допустимы `> 5%` и «превышает/больше/более 5%».  
L2-03/04: в task явно единственный лист (`Сводка` / `ИФА`) и формулы Excel.
