## Текущее задание

Проживание по командировке №22 проекта К-24 превысило лимит сметы. Было ли получено отдельное согласование, и если да — каким документом и на какую дату?

## Формат результата

Создайте файл `output/answer.json` со структурой ниже.
Пример показывает **только форму** полей — не подставляйте его как готовый ответ.
Если данных недостаточно — отказ: `answer` = null и `refused` = true.

```json
{
  "answer": {
    "approved": false,
    "doc_id": "XX-00-00",
    "date": "YYYY-MM-DD"
  },
  "sources": [
    "..."
  ],
  "refused": false
}
```

Затем завершите задачу (`claim_done`).
