## Текущее задание

Сегодня 27.05.2026. Каков последний день срока направления Поставщику претензии о неустойке по заявке З-8 по договору ПС-2026-17 по внутреннему Положению и истёк ли этот срок на сегодняшнюю дату?

Поле `expired`: true если срок истёк, false если не истёк (включая случай «сегодня последний день»).

## Формат результата

Создайте файл `output/answer.json` со структурой ниже.
Пример показывает **только форму** полей — не подставляйте его как готовый ответ.
Если данных недостаточно — отказ: `answer` = null и `refused` = true.
В `sources` указывайте пути **относительно корня рабочей папки** (например `проекты/ПС-2026-17/...`), не только имя файла.

```json
{
  "answer": {
    "deadline": "YYYY-MM-DD",
    "expired": false
  },
  "sources": [
    "..."
  ],
  "refused": false
}
```

Затем завершите задачу (`claim_done`).
