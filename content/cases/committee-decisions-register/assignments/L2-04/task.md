## Текущее задание

Создайте `output/справка_руководителю.pptx` ровно из **четырёх** слайдов:

1. «Общий статус» — числа: всего, в работе, просрочено, отменено.
2. «Статус по комитетам» — таблица/строки по комитетам.
3. «Топ-5 просроченных» — по правилу регламента (дни просрочки ↓, ID ↑).
4. «Переносы и отмены» — перечислите ID с переносами и ID отменённых.

Визуальная красота не оценивается; важны открываемость, 4 слайда, заголовки и корректные числа.
