## Текущее задание

Соберите файл `output/реестр_решений.xlsx` (один лист `Реестр`).

Одна строка на каждое решение, колонки строго:
`ID`, `Комитет`, `Решение`, `Ответственный`, `Первоначальный срок`, `Актуальный срок`, `Статус`, `Файлы-источники`.

- Статусы: «ОТМЕНЕНО» / «ПРОСРОЧЕНО» / «В работе» по правилам регламента на 2026-08-18.
- `Файлы-источники` — имена файлов через `; ` в порядке цепочки событий.
- Строки отсортируйте по `Актуальный срок` по возрастанию, при равенстве — по `ID`.

Исходные файлы не изменяйте.
