## Текущее задание

Соберите файл `output/журнал_изменений.xlsx` (лист `Журнал`).

Одна строка на событие. Колонки:
`ID`, `Дата события`, `Тип`, `Старое значение`, `Новое значение`, `Файл-источник`, `Состояние после события`.

Тип: `Создание` / `Перенос` / `Отмена`.
`Состояние после события` — статус, который имел бы решение сразу после этого события при той же дате среза 2026-08-18.
Сортировка: по дате события, затем по ID, затем по типу (Создание < Перенос < Отмена).
