# Регламент учёта решений комитетов

## Дата среза

Все статусы исполнения определяются **по состоянию на 2026-08-18**.

## Статус решения

1. Если решение отменено — статус «ОТМЕНЕНО».
2. Иначе, если актуальный срок исполнения **строго раньше** даты среза (2026-08-18) — статус «ПРОСРОЧЕНО».
3. Иначе — статус «В работе».

Срок, равный дате среза (2026-08-18), **не** является просроченным.

## Действующая версия

При нескольких изменениях по одному ID действует **последнее событие по дате заседания** протокола, в котором оно зафиксировано.
Отмена решения **терминальна**: после отмены переносы срока не допускаются.

## Топ просроченных решений

Для управленческих сводок топ-5 просроченных решений формируется так:
1. по числу дней просрочки (дата среза минус срок) — по убыванию;
2. при равенстве — по ID решения по возрастанию.
